# Week 2 — Teach Your Robot to Sense

**Big idea:** A robot understands the world through **sensors**. This week: distance (ultrasonic) and line (IR).

**Pipeline:**

```text
Sensor → numbers → Serial / decisions → LED or buzzer
```

Still no motors. Sense → Think first; Act with wheels comes in Week 3.

## Programs

| # | Folder | What you learn |
|---|--------|----------------|
| 05 | `05_ultrasonic_distance/` | Measure distance in cm |
| 06 | `06_distance_decision/` | Too-close warning (threshold decision) |
| 07 | `07_line_sensors/` | Read IR line sensors (L/C/R) |
| 08 | `08_sensor_dashboard/` | Combine sensors into one report |

**Week 2 complete** when Program 08 works and students can explain:

> Sensors produce numbers. Rules turn numbers into decisions. A dashboard reports everything in one place.
