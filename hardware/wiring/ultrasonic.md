# Ultrasonic HC-SR04 wiring

```text
HC-SR04     Arduino Uno
-------     -----------
VCC     →   5V
GND     →   GND
TRIG    →   pin 9
ECHO    →   pin 10
```

## Tips

- Face a flat wall or hand for stable readings
- Soft / angled surfaces can give noisy values
- Never connect HC-SR04 VCC to 3.3V on Uno projects in this course
