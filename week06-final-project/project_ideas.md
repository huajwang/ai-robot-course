| Object-Following Robot | `bottle` or `cup` + FOLLOW | Track classroom object |

| Smart Classroom Robot | `person` + `book` / `laptop` | Count people on HUD |

| Rescue Robot | PATROL + STOP on person | “Found someone!” banner |
| Recycling Robot | `bottle` + GUARD/FOLLOW | LED/buzzer when found |

Write 3 sentences: what you changed, why, and what the robot does now.
